# 排班站对齐修复 + 编辑页清除拆分 + 周视图设计

日期：2026-08-20
状态：已确认

## 背景

用户反馈排班站展示页与编辑页左侧"场次/角色"栏与右侧日期表格完全错位；编辑页清除功能需拆分；编辑页需增加排班表入口；两页需改为 7 天周视图。

## 设计决策（已与用户逐项确认）

### 1. 对齐修复（展示页 + 编辑页同步）
- 错位根源：左右双容器各自独立表格，右侧表头"日期+星期"两行内容高于左侧"场次/角色"一行表头，导致 tbody 起始位置不一致；个别单元格内容撑高进一步加剧错位。
- 方案 A（用户已选）：统一行高模型
  - 左右 thead th 统一固定高度（容纳右侧日期+星期两行），左侧文字垂直居中
  - 所有 td（slot-col/role-col/cell）统一固定行高、单行不换行（white-space:nowrap）、溢出裁剪
  - 保持左右双容器 flex 物理独立，不改架构
- 覆盖范围：render_web.py（CSS_TEMPLATE/PAGE_JS，生成 index.html）与 editor.html（CSS_VIEW + 渲染逻辑）

### 2. 清除功能拆分（编辑页）
- 移除现有"清除日期范围"prompt 弹窗流程
- 新增「清除选定日期」按钮：点击日期表头选中整列（高亮）→ 点击按钮 → confirm 确认 → 删除当前直播间该日期全部场次数据 → save 写回发布
- 新增「清除全部」按钮：confirm 确认（明示清空当前直播间全部数据）→ 删除当前直播间 schedule[room] 整个对象 → save 写回发布
- 均带二次确认，沿用现有 save 逻辑

### 3. 前往排班表入口（编辑页）
- 顶部工具栏新增「前往排班表」链接，跳转 index.html（同目录）

### 4. 7 天周视图（展示页 + 编辑页）
- 默认显示本周（周一至周日），仅 7 个日期列
- 表格上方新增「上周 / 下周」按钮，按自然周切换
- 不限制翻页边界，无数据周显示空白表格
- 周末列保留但留空（符合"周末不排班"偏好）
- 当前周内"今天"列高亮标记
- 展示页静态 JS 维护 weekStart 状态并重渲染；编辑页同步支持，清除/复制粘贴等均作用于当前可见列

## 数据流
- 周窗口由前端 JS 状态（weekStart，周一日期）驱动，不再依赖 config.json 的 display_dates 固定列表
- schedule.json 结构不变（rooms → 日期 → 场次 → {time, car, anchor}）
- 排班提醒（nextRemind）逻辑不受周窗口影响，仍按全量数据取未来最近一场

- 修改后需在本地打开验证展示页/编辑页渲染与对齐，再部署 GitHub Pages
