# 移动端排班表列宽调整设计（2026-08-21）

## 背景与问题

移动端（≤640px）排班表只显示当日一列后，左侧「场次/角色」列过窄导致文字溢出：
- 角色列 58px 放不下「直播时间」4 字（12.5px 字体 + padding），文字顶出单元格边界，视觉上呈乱码/溢出。
- 右侧当日列 96px 过宽，挤压了左侧面板的空间。

## 方案（用户选定 B）

移动端 640px 媒体查询内的列宽调整为：

| 列 | 原值 | 新值 |
|---|---|---|
| 当日日期列（.date-col） | 96px | 72px |
| 场次列（.slot-col / .col-slot） | 55px | 58px |
| 角色列（.role-col / .col-role） | 58px | 72px |
| 左面板总宽（.left-panel） | 123px | 136px |

说明：
- 当日列 72px 仍可完整显示「08/21」+「周五」两行。
- 角色列 72px 可完整容纳「直播时间」等 4 字内容。
- 左面板总宽 = 58 + 72 + border-spacing 6px = 136px。

## 同步范围

展示页与编辑页双处同步：
- `render_web.py` CSS_TEMPLATE 的 640px 媒体查询块
- `editor.html` 主 CSS 的 640px 媒体查询块
- `editor.html` CSS_VIEW（发布预览模板）如含独立日期列宽度定义，需一并核对

## 验证

1. `python3 render_web.py` 重新生成 `output/schedule.html`，`cp` 为 `index.html`
2. browser-agent 375px 视口实测：
   - 角色列文字「直播时间/直播车型/主播」完整显示，无溢出
   - 当日列「08/21 周五」完整显示，无截断
   - 无横向滚动、无列错位
3. 桌面端（≥1024px）整周 7 列不受影响
4. 部署推送 GitHub Pages，确认线上生效

## 范围外

- 桌面端列宽保持不变
- 编辑页预览以外的交互逻辑不调整
