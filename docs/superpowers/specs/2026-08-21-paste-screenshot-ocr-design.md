# 粘贴截图自动识别填充 — 设计文档

日期：2026-08-21
状态：已确认

## 背景与目标

极氪日播间排班站编辑页（editor.html）当前支持「复制粘贴」文本排班解析。用户反馈：电脑上排班表（Excel/网页）复制文本时格式经常错乱，希望改为**直接截图粘贴**，由页面自动识别表格内容并填充到排班数据中。

核心需求：在编辑页新增「粘贴截图」入口，用户截图后 Ctrl+V / Cmd+V 粘贴，页面 OCR 识别表格 → 解析 → 可编辑预览 → 确认写入。

## 表格结构约定（用户确认）

- 截图表格为 **5 列 × 30 行**：列 = 周一至周五；行 = 每天 6 场（每 5 行 = 1 场）
- 每场 5 行结构：时间行 / 车型行 / 主播行1 / 主播行2 / 主播行3
- 只需提取：**时间、车型、第一个主播**；第 4~5 行（后续主播/助手）忽略
- 空场次留空
- 时间自动归入第 1~6 场（复用 slotByStart 规则）

## 方案：C（本地 OCR + 复用现有解析）

### 技术选型

- **Tesseract.js 纯前端 OCR**：全程本地识别，无服务器、无密钥、无费用；任何人打开网页即可用，无需安装
- 首次加载 OCR 模型约 10MB（CDN 加载，选国内可达源并随项目托管模型，避免 CDN 不可达）
- 识别速度：普通电脑 2~5 秒/张；手机 6~10 秒/张；浏览器缓存后再次打开秒级
- 识别结果经解析后进入**可编辑预览**，OCR 误差由人工修正兜底

### 功能流程

```
用户截图 → 编辑页按 Ctrl+V / Cmd+V（或点「粘贴截图」按钮）
  → 捕获剪贴板图片
  → Tesseract.js OCR 识别 → 表格文本
  → 复用 parseTableText 解析（时间行锚点 + 车型/主播归类 + 场次归档）
  → 弹出可编辑预览表格（时间/车型/主播单元格可直接修改）
  → 确认写入 → 保存
```

### 页面改动（editor.html 单文件）

| 改动点 | 说明 |
|--------|------|
| 新增「粘贴截图」按钮 | 放在现有「复制粘贴」按钮旁 |
| 监听 paste 事件 | 剪贴板含图片 → 走截图识别；含文本 → 走原文本粘贴 |
| 引入 Tesseract.js | CDN 加载（国内可达源），模型文件随项目托管 |
| 复用解析逻辑 | `parseTableText` 不变，OCR 文本直接作为输入 |
| 预览表格可编辑 | 现有只读预览改为可编辑（时间/车型/主播单元格可点击修改） |
| 写入逻辑复用 | 复用现有 confirmPaste 写入流程 |

### 解析规则

- 5 列 = 周一至周五，按列匹配当前周 displayDates
- 每 5 行 = 一场：时间行 / 车型行 / 主播行1 / 主播行2 / 主播行3
- 提取时间、车型、第一个主播；后续行忽略
- 按时间自动归入第 1~6 场，空场次留空

### 错误处理

- OCR 失败 / 无有效时间行 → 提示「未识别到有效数据，请确认截图清晰或手动粘贴」
- 识别有误 → 预览表格直接编辑修正
- 日期超出当前周 → 忽略并提示（沿用现有逻辑）
