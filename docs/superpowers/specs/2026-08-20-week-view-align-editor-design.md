# 排班站周视图 + 对齐修复 + 编辑页功能迭代设计

日期：2026-08-20

## 背景

用户反馈：左侧"场次/角色"栏与右侧日期表格完全错位（展示页 + 编辑页）；编辑页清除功能需拆分；编辑页需增加前往排班表入口；表格改为只显示 7 天，通过上周/下周切换。

## 需求

1. **对齐修复**：展示页 + 编辑页左右双容器逐行对齐。
2. **清除功能拆分**（编辑页）：清除选定日期（点击日期表头选中列后清除该列）、清除全部（清空当前直播间全部数据）。
3. **前往排班表入口**（编辑页）：工具栏新增链接跳转 index.html。
4. **7 天周视图**（展示页 + 编辑页）：默认显示本周（周一至周日），上周/下周按钮按自然周切换，不限制翻页边界，周末列保留留空，今天列高亮。

## 设计

### 1. 对齐修复（方案 A：统一行高模型）

- 左右 `thead th` 统一固定高度（展示页 56px、编辑页含删除本列占位 74px），`vertical-align:middle`，消除表头高度差导致的 tbody 起始偏移。
- 所有 `td` 统一固定行高、`white-space:nowrap`、溢出裁剪，杜绝内容撑高错开。
- 左右双容器 flex 物理独立架构不变（方案 A）。

### 2. 清除功能拆分（editor.html）

- 移除原"清除日期范围"弹窗（prompt 输入起止日期）。
- **清除选定日期**：点击日期表头 `th.date-col` 选中整列（表头 `.selected` + 该列所有 td `.col-selected` 高亮）；点击按钮 → confirm 二次确认 → 删除 `schedule[room][date]` → 保存发布。
- **清除全部**：confirm 二次确认（提示清空当前直播间全部数据）→ 删除 `schedule[room]` → 保存发布。
- 沿用现有 GitHub API 保存逻辑。

### 3. 前往排班表入口（editor.html）

- 工具栏最左新增 `<a class="btn-ghost" href="index.html">← 前往排班表</a>`。
- 移动端 375px 不再隐藏（`.btn-ghost{display:none}` 改为紧凑可见样式）。

### 4. 7 天周视图（index.html + editor.html）

- 周窗口：`mondayOf(now)` 起 7 天，`WEEKDAYS` 数组按 `getDay()` 索引改为 `["周日","周一",...]`（修复星期偏移一天的 bug）。
- 展示页：顶部 `week-nav`（上周 / `week-label` / 下周），服务端 `current_week_dates()` 生成初始本周；客户端 `shiftWeek(n)` 重渲染并同步 `week-label`。
- 编辑页：工具栏 `week-label` + 上周/下周按钮，`displayDates` 基于 `thisMonday` 动态计算；粘贴解析若目标日期不在当前周，自动切到该日期所在周并选中。
- 今天列高亮 `.date-col.today`。
- 清除/复制粘贴等操作均作用于当前可见 7 列。
