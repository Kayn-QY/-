# 极氪日播间排班 · 多直播间版设计文档

日期：2026-08-19
状态：已确认

## 背景

排班站目前仅支持单一【7X官方直播间】排班表。用户需要将网站改为「极氪日播间排班」，支持 7X、8X、9X、猎装 四个直播间的独立排班表，并通过左下角 Excel 式 Sheet 标签切换；后续可继续增加更多直播间。

## 需求确认

1. 网站名称标题改为「极氪日播间排班」
2. 左下角 Sheet 标签切换直播间排班表（类似 Excel 底部工作表标签）
3. 四个直播间表格结构完全相同：横向日期、纵向第 1-6 场，每场含直播时间/直播车型/主播/技术/投流
4. 开播提醒覆盖四个直播间（只提醒主播）
5. 8X / 9X / 猎装 先建空表结构，数据后续提供截图再填
6. 后续可继续增加更多直播间

## 方案选择

采用方案 1：schedule.json 加直播间层级 + 左下角 Sheet 标签切换。改动集中，与现有编辑/提醒/部署管道兼容。

## 架构设计

### 数据层

- `schedule.json` 结构升级：
  ```json
  {
    "7X": {"2026-08-14": {"第1场": {"time": "10:00-12:00", "car": "7×", "anchor": "李润霞", "tech": "升级玻璃", "ad": "徐光辉"}}},
    "8X": {},
    "9X": {},
    "猎装": {}
  }
  ```
- 现有 7X 数据自动迁移：原 `{"date": {...}}` 包一层 `{"7X": ...}`
- `config.json` 增加 `rooms: ["7X", "8X", "9X", "猎装"]`，`display_dates` 保持不变

### 页面层（index.html / render_web.py）

- 标题与 hero 主标题改为「极氪日播间排班」
- 左下角固定毛玻璃 Sheet 标签栏：每个直播间一个标签（如 `7X | 8X | 9X | 猎装`），点击切换对应排班表，激活标签高亮
- 「＋」按钮新增直播间：输入直播间名 → 校验非空/不重复 → 写入 config.json rooms + schedule.json 空结构 → 重新渲染部署
- 每个直播间一张独立表格（沿用现有毛玻璃 3D 风格）：横向日期、纵向第 1-6 场、每场含直播时间/直播车型/主播/技术/投流
- 无数据的直播间正常渲染空表，单元格留白占位
- 切换逻辑：纯前端 JS 控制 `.room-table` 显示/隐藏，无需整页刷新

### 编辑层（editor.html）

- 顶部增加直播间切换（与左下角 sheet 同步）
- 编辑保存时写入对应直播间层级

### 提醒层（reminder.py）

- 遍历 config.rooms 下所有直播间
- 按场次时间提前 10 分钟提醒主播开播
- 通知内容带直播间名，如「7X · 10:00 李润霞开播」

## 数据流

1. 渲染：config.json(rooms + display_dates) + schedule.json → render_web.py → index.html（N 张表 + Sheet 栏 + 切换 JS）
2. 编辑：editor.html → GitHub API → 写回 schedule.json / config.json → 重新生成 index.html
3. 提醒：reminder.py → schedule.json → macOS 通知

## 边界与错误处理

- 新增直播间名校验：非空、不与现有 rooms 重复
- 空表：无数据时正常渲染空单元格，不报错
- 旧数据迁移：渲染时检测顶层是否含日期键（旧结构），是则包一层 7X

## 测试

- 本地生成页面：四个 Sheet 标签存在、点击切换正常、7X 数据完整、8X/9X/猎装 空表正常
- reminder.py dry-run：遍历四个直播间输出提醒
- 线上验证：index.html / editor.html HTTP 200，含「极氪日播间排班」标题与四标签结构
