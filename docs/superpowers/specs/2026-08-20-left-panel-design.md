# 排班站左侧独立列组设计（2026-08-20）

## 背景
用户反馈：当前排班页与在线编辑页中「场次」「角色」两列是表格内 sticky 模拟固定，视觉上与日期表格"融为一体"，在部分环境渲染异常。需求：将两列改为**真正独立的左侧面板**，与右侧日期表格物理分离。

## 范围
- 应用页面：排班展示页（index.html，由 render_web.py 生成）+ 在线编辑页（editor.html）
- 数据与逻辑不动，仅改页面结构与 CSS

## 布局方案（方案 A：左右双容器 flex）
- 外层一个纵向滚动容器（`.schedule-wrap`）
- 内部 flex 左右两块：
  - 左：`.left-panel` 独立面板，固定宽度，包含「场次」「角色」两列并排（场次列、角色列各约 84px/80px）
  - 右：`.right-scroll` 独立容器，`overflow-x:auto` 承载日期表格，横向滚动
- 行高固定 44px，左右两侧行天然对齐
- 纵向：同属外层容器一起滚动；横向：仅右侧滚动，左侧纹丝不动

## 视觉
- 左侧面板沿用毛玻璃浅色风格（`rgba(244,248,255,.98)` 类浅色底、圆角、右侧边缘 1px 分隔线 + 阴影）
- 表头行（场次/角色/日期）与数据行保持一致背景，避免纵向滚动穿帮
- 面板宽度固定，右侧表格占用剩余宽度

## 结构
```
<div class="schedule-wrap">            <!-- 纵向滚动容器 -->
  <div class="left-panel">             <!-- 固定，不横向滚动 -->
    <table> 表头：场次 | 角色 </table>
    <table> 数据行：第N场 | 角色名 </table>
  </div>
  <div class="right-scroll">           <!-- overflow-x:auto -->
    <table> 表头：日期1 日期2 ... </table>
    <table> 数据行：单元格 ... </table>
  </div>
</div>
```

## 改动文件
- `render_web.py`：HTML_TEMPLATE / CSS_TEMPLATE / 表格渲染函数，生成左右分离结构
- `editor.html`：CSS_VIEW / PAGE_JS / renderTable 函数，同样改为左右分离
- 两个页面的 CSS 保持一致（render_web.py 与 editor.html 模板同步）
- 重新生成 index.html / output/schedule.html 并部署

## 兼容性
- 编辑页「删除本列」「新增日期列」「清除」「复制粘贴」等逻辑不变，仅布局容器变化
- 排班页提醒卡片、直播间切换等布局不变
- 移动端窄屏下保持左右分离（左面板固定，右表格横向滚动）

## 验收标准
- 两页面左侧均为独立面板，与右侧表格物理分离，视觉有分隔线与阴影
- 横向滚动右侧时左侧面板完全不动；纵向滚动时两侧同步
- 行高对齐无错位；日期表头与编辑操作按钮正常
